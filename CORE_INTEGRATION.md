# اتصال به AS Academy Core

این ریپو Course Package اختصاصی Python است و هسته مشترک آکادمی را تکرار نمی‌کند.

## متعلق به `as-academy-core`
- Navigation و Design System
- Progress و Bookmark
- Quiz/Exercise engine
- Search و Settings
- Content Engine/Updater
- Course schema/contract
- Database/Room و منطق عمومی برنامه

## متعلق به این ریپو
- محتوای آموزشی Python
- مثال‌ها و تمرین‌های Python
- پروژه‌های Python
- آزمون‌ها و metadata اختصاصی Python
- Branding/Capability اختصاصی دوره Python

هر تغییر در منطق مشترک باید ابتدا در Core انجام شود و این ریپو فقط قرارداد Core را مصرف کند.

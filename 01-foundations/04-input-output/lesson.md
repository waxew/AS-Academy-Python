# درس 04 — ورودی و خروجی

## اهداف
- دریافت داده با `input()`
- تبدیل ورودی متنی به عدد
- خروجی خوانا با f-string

```python
name = input("نام: ").strip()
age = int(input("سن: "))
print(f"{name}، سال آینده {age + 1} ساله می‌شوی.")
```

## نکته
`input()` همیشه `str` برمی‌گرداند؛ بنابراین برای محاسبات باید تبدیل نوع انجام شود.

## تمرین
قیمت و تعداد کالا را دریافت و مبلغ کل را با جداکننده هزارگان چاپ کنید.

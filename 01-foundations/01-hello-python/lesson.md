# درس 01 — Hello Python

## هدف
شناخت Interpreter و اجرای اولین فایل `.py`.

## مثال
```python
print("Hello, Python!")
```

`print` داده را در خروجی استاندارد نمایش می‌دهد. رشته داخل کوتیشن یک مقدار `str` است.

## تمرین
برنامه‌ای بنویسید که نام، شهر و هدف شما از یادگیری Python را در سه خط چاپ کند.

## آزمون
1. پسوند متداول فایل Python چیست؟
2. `print()` چه کاری انجام می‌دهد؟
3. تفاوت اجرای REPL و فایل `.py` چیست؟

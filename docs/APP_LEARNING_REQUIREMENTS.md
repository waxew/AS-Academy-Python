# الزامات تجربه یادگیری Python در اپ

## صفحه Home
- ادامه آخرین درس
- درصد پیشرفت کلی
- سطح فعلی
- درس‌های پیشنهادی برای مرور
- دسترسی به Search، Bookmark، Projects و Glossary

## صفحه سطح
- فصل‌های مرتب‌شده
- درصد پیشرفت هر فصل
- وضعیت قفل/باز
- پروژه پایانی سطح

## صفحه درس
- عنوان و زمان تقریبی
- متن فارسی RTL
- Code Block با syntax highlight
- دکمه Copy
- Run برای مثال‌های مجاز
- Output Block
- Tip/Warning/Important
- Exercise
- Quiz
- Bookmark
- Previous/Next
- Mark Complete

## ارزیابی
- حداقل 70٪ برای Quizهای اجباری
- تمرین پس از مفاهیم کلیدی
- Mini Project پایان فصل
- Project پایان سطح
- Capstone پایان دوره

## مرزبندی با Core
تمام UI، Navigation، Progress، Bookmark، Search، Quiz Runtime، Exercise Runtime، Database و Content Loader در `AS-Academy-Core` هستند. این ریپو فقط محتوای Python، capabilityها، metadata و پروژه‌های اختصاصی Python را نگه می‌دارد.

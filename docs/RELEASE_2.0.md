# Python Course Package 2.0

این نسخه milestone تکمیل مسیر اصلی آموزشی است.

## موجود
- شش سطح استاندارد Core
- مسیر آموزشی از اولین برنامه تا Production
- محتوای مبانی، مقدماتی، متوسط، پیشرفته و تخصصی
- تمرین و Quiz در طول مسیر
- بانک Quiz و Exercise
- پروژه‌های سطحی و تخصصی
- آزمون جامع
- Capstone نهایی
- Glossary
- Progression/Completion rules
- Portfolio پیشنهادی

## سیاست توسعه بعد از 2.0
نسخه 2.0 به معنی پایان مسیر اصلی curriculum است، نه توقف توسعه محتوا. نسخه‌های بعدی می‌توانند تعداد مثال‌ها، تمرین‌ها، سؤال‌ها، پروژه‌های اختیاری و مسیرهای تخصصی جدید را افزایش دهند بدون تغییر هدف و معماری اصلی دوره.

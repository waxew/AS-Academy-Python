# Capstone — Python Production Project

هنرجو یک سامانه کامل انتخاب می‌کند: فروش، CRM، نوبت‌دهی یا مدیریت محتوا.

الزامات: معماری لایه‌ای، PostgreSQL، API، authentication، validation، logging، tests، Docker، CI و مستندات اجرا.

مسیر AI اختیاری: افزودن جستجوی semantic یا RAG با ارزیابی کیفیت retrieval.

# AS Academy Python — Curriculum v2.0

مسیر نهایی دوره از صفر تا Production:

1. مبانی: نصب، Syntax، Type، I/O، Operator، String، Condition، Loop، Collection، Function
2. مقدماتی: Module/Package، venv/pip، File/Pathlib، JSON/CSV/XML، Exception، Comprehension، Debugging/Logging
3. متوسط: OOP، Inheritance/Composition، Polymorphism، Dataclass، Enum، Property، Type Hints، Protocol، Iterator/Generator
4. پیشرفته: Decorator، Context Manager، Regex، Date/Time، Dunder، Threading، Multiprocessing، Queue/Lock، AsyncIO، pytest/Mock، Packaging، Profiling
5. تخصصی: SQL/SQLite/PostgreSQL، ORM/Migration، HTTP/REST، Flask/FastAPI/Django/DRF، Tkinter/PySide، Scraping/Automation، Bot، NumPy/Pandas/Visualization، ML، LLM/Embedding/RAG، Network، Security، Docker، CI/CD/Deployment
6. پروژه‌محور: پروژه سطحی، Portfolio و Capstone Production

هر بخش در Course Package با ترکیبی از PARAGRAPH، CODE، OUTPUT، TIP/WARNING، EXERCISE، QUIZ، PROJECT و DIAGRAM برای Content Engine هسته ارائه می‌شود.

## معیار پایان دوره
- تکمیل مسیر اجباری
- پروژه پایان هر سطح
- آزمون جامع حداقل 70٪
- قبولی Capstone

Shared runtime همچنان در AS-Academy-Core باقی می‌ماند؛ این repository فقط محتوای Python و metadata اختصاصی آن را نگه می‌دارد.

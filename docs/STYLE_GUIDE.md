# استاندارد سورس آموزشی

- Python 3.11+
- رعایت PEP 8
- نام‌گذاری واضح
- Type Hint برای APIهای آموزشی
- Docstring برای module/class/function
- کامنت برای «چرایی» منطق و نکات آموزشی؛ از کامنت‌های بی‌ارزش که صرفاً خود کد را تکرار می‌کنند پرهیز شود.
- مثال‌ها کوچک، قابل اجرا و قابل تست باشند.
- کلید، Token و Secret هرگز commit نشود.

# سیستم ارزیابی دوره

- Quiz کوتاه بعد از هر درس
- Exercise بعد از هر مفهوم کلیدی
- Mini Project در پایان هر فصل
- Project در پایان هر سطح
- Capstone نهایی

پیشنهاد امتیاز: Quiz 15%، Exercises 25%، Level Projects 30%، Capstone 30%.

Progress، Quiz runtime و persistence جزو مسئولیت `as-academy-core` هستند؛ این ریپو فقط محتوا و answer metadata اختصاصی Python را فراهم می‌کند.

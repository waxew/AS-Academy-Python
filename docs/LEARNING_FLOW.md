# جریان یادگیری داخل برنامه Python

هدف اصلی اپ این است که کاربر وارد شود و واقعاً Python یاد بگیرد.

جریان اصلی:

Home → ادامه یادگیری → سطح → فصل → درس → مثال کد → تمرین → Quiz → علامت تکمیل → درس بعدی.

در پایان هر فصل یک Mini Project و در پایان هر سطح یک Level Project قرار می‌گیرد. آخر دوره Capstone نهایی باز می‌شود.

نمای درس باید به کمک Core این امکانات را داشته باشد: متن فارسی RTL، بلوک کد Python، خروجی کد، Copy، Code Runner در صورت فعال بودن، Bookmark، Progress، Quiz، Exercise، Search و Previous/Next lesson.

هیچ‌کدام از منطق‌های Navigation، Progress، Bookmark، Search، Quiz Engine یا Database در این ریپو دوباره پیاده‌سازی نمی‌شوند؛ همه از `AS-Academy-Core` مصرف می‌شوند.
